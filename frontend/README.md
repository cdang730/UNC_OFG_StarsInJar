## Structure
- assets contains all the transparent background pictures of the logo and stars. 
  - need to add more pictures of the star TwT
- components folder:
  - individual components of each page. 
  - Jar.tsx contain the svg jar. 
- data folder: 
  - the mocking/placeholder data for now. 
  - starImages.ts contain the logic that frontend use to get all star pictures from the assets folder. 
- pages folder:
  - three different pages's format and words/controls. 
  - need to update mission page. 
  - need to update gallery page's gallery title color. 
- src: 
  - App.tsx: switch page logic. 
  - index.css: pre-define all the elements/padding, colors, and style for each page. 
  - main.tsx: website frontend structure.
